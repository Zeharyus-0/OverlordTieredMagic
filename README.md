# Overlord: Tier Magic (for Isekai RPG Leveling)

A RimWorld magic overhaul by Zeharyus, built on [Isekai RPG Leveling](https://steamcommunity.com/sharedfiles/filedetails/?id=3657580708). Package ID `Zeharyus.OverlordTierMagic`. RimWorld 1.6 and 1.7.

**Required:** Harmony and Isekai RPG Leveling (`JellyCreative.IsekaiLeveling`). Load order: Harmony, Isekai RPG Leveling, this mod.

## What it adds

- **Tier Magic:** 158 spells (0th to 10th tier plus Super-Tier), three caster paths (Arcane, Divine, Spiritual), mana, six metamagic toggles, rank-based resistance. Time Stop freezes the map for 12 seconds.
- **The Geass:** a one-per-colony class with a contract scene, commands, followers, the runaway and the second eye. See [docs/GEASS.md](docs/GEASS.md).
- **The Almighty:** a one-per-colony class of future sight (Look Back and Look Ahead, Schrift letters, Schatten, Blut Vene and Arterie, and more).
- **Enemy casters:** hostile humans of rank C or higher can get a path and a spell build.
- **Souls and guardians:** seal the soul of a worthy colonist and bind it to a statue that builds a spirit body. See [docs/SOULS.md](docs/SOULS.md).

The full feature description is in `About/About.xml`.

## Install (players)

Download the zip from **Releases**, unzip it into your RimWorld `Mods` folder so that `Mods/OverlordMagic/About/About.xml` exists, then enable Harmony, Isekai RPG Leveling and this mod in that order.

## Compatibility

Optional support, active only when the other mod is loaded: Facial Animation (Nals), Layered Apparel (costel), Dubs Bad Hygiene, Vanilla Social Interactions Expanded. Details in [docs/COMPAT.md](docs/COMPAT.md).

## Build from source

The repo is not the playable mod: the compiled DLL is not in the repo (it goes in the Release).

1. Clone this repo into `RimWorld/Mods/` so the folder is `Mods/OverlordMagic`.
2. Open a terminal in `Source/OverlordMagic` and run `dotnet build -c Release`. The project finds the RimWorld folder four levels up and Isekai in the Steam workshop folder; override with `-p:RimWorldPath="..." -p:IsekaiPath="..."` (see the comment in `OverlordMagic.csproj`).
3. The DLL is written to `Assemblies/`. The project needs the game's `RimWorldWin64_Data/Managed` folder (on the 1.7 beta it may be missing; use a saved copy of the 1.6 one).

Defs and icons are partly generated by the Python scripts in `Source/` (`gen*.py`, need Pillow).
