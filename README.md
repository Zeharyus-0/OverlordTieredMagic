Overlord: Tier Magic (for Isekai RPG Leveling)

A RimWorld magic mod by Zeharyus: 158 spells, The Geass, The Almighty and soul guardians, all built on Isekai RPG Leveling. RimWorld 1.6 and 1.7.

Everything the mod does is explained in the presentation: Overlord_Tier_Magic_presentation.pdf

Install
Install Harmony and Isekai RPG Leveling.
Download the zip from Releases and unzip it into your RimWorld Mods folder, so Mods/OverlordMagic/About/About.xml exists.
Load order: Harmony, Isekai RPG Leveling, this mod.
Build from source
